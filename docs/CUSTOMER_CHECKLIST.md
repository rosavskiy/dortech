# Материалы от Заказчика (Приложение 3, п. 2 — до 27.10.2026)

Отметьте, что передано. Недостающее заменяется демонстрационными данными, а срок зависящих этапов сдвигается на документально подтверждённую задержку.

## Контент и каталог
- [ ] Перечень техники (до 50 карточек): название, категория, производитель, модель, год, характеристики, статус доступности, условия аренды — удобно в таблице (шаблон CSV предоставим)
- [ ] Фотографии техники (jpg/png, от 1200 px по длинной стороне) с правами на использование
- [ ] Тарифы: цена за смену (часов в смене) и за сутки по каждой единице, минимальный срок; перечень дополнительных услуг с фиксированной стоимостью; правило округления; НДС включён/не включён
- [ ] Услуги (до 10): название, краткое и полное описание, фото
- [ ] Выполненные проекты (до 10): название, год, заказчик, место, описание, фото
- [ ] Публикации (до 10): заголовок, дата, текст, фото
- [ ] Текст «О компании», цифры для главной (лет на рынке, единиц техники и т. п.)
- [ ] Контакты: телефон, email, адрес, режим работы, координаты для карты
- [ ] Политика обработки персональных данных и согласие (текст юриста Заказчика)
- [ ] Логотип (svg/png), фирменные цвета и шрифт, если есть брендбук

## Доступы и сервисы
- [ ] Рабочее доменное имя и доступ к DNS (или контакт регистратора)
- [ ] Сервер для рабочей среды: 4 vCPU, 8 ГБ RAM, SSD, Ubuntu 24.04, доступ по SSH (root или sudo)
- [ ] SMTP для исходящей почты: хост, порт, логин, пароль, адрес отправителя
- [ ] Адрес приёмника webhook (если есть внешняя система) — иначе проверим встроенным тестовым приёмником
- [ ] Список сотрудников: администратор (ФИО, email), менеджеры (ФИО, email)

## Решения
- [ ] Показывать ли цены публично или только «по запросу» (можно по каждой карточке отдельно)
- [ ] Менеджеры видят все заявки или только назначенные им
- [ ] Как считать смены: по календарным дням или по рабочим
- [ ] Нужны ли коэффициенты (ночная смена, выходные) или достаточно фиксированных доп. услуг
- [ ] Ответы на вопросы по прототипу — в течение двух рабочих дней после показа 28.10
