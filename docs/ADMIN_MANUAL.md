# Инструкция администратора

Панель управления: `https://<домен>/<ADMIN_URL_PATH>/` (адрес выдаётся при передаче). Вход — email и пароль сотрудника с ролью «Администратор» (менеджерам доступны только разделы заявок, организаций и сообщений). Кабинет менеджера на сайте: `https://<домен>/manager/`.

## Роли

| Роль | Доступ |
|---|---|
| Клиент | Личный кабинет: свои заявки, файлы, профиль организации |
| Менеджер | Кабинет менеджера (все заявки, статусы, назначение, комментарии, PDF-предложения, CSV) + панель: заявки, организации, сообщения с сайта |
| Администратор | Всё: каталог, тарифы, контент, пользователи, роли, блокировка, импорт, webhook, журнал |

Роль и блокировка задаются в панели → **Пользователи**. При установке «Заблокирован с» все сессии пользователя завершаются немедленно, вход и панель становятся недоступны; очистите поле, чтобы разблокировать. Пароль сотрудника меняется там же (поле «Пароль» — введите новый).

## Каталог техники

1. **Категории** — до двух уровней (родительская категория). У каждой: название, адрес (slug, латиница — часть URL `/catalog/<slug>`), описание, изображение, «На главной», SEO-поля. В поле «Характеристики категории» выберите, какие характеристики заполняются у техники этой категории — они же становятся фильтрами.
2. **Характеристики (словарь)** — код (латиница, используется в CSV как `attr:<код>`), название, единица, тип: число / строка / да-нет / выбор из списка. «Фильтр в каталоге» и «В сравнении» включают использование. Для типа «выбор» варианты добавляются в **Варианты характеристик**.
3. **Производители**, **Статусы доступности** (код, название, цвет, «можно добавить в заявку»).
4. **Техника** — карточка: название, адрес, внешний ID (для CSV), категория, производитель, модель, год, доступность, краткое описание, описание и условия (визуальный редактор), «Опубликована», «На главной», «Скрыть цену» (вместо тарифа показывается «запросить предложение»), SEO-поля.
   - **Тарифы** — отдельная запись на карточку: цена за смену, за сутки, часов в смене, минимум смен/суток.
   - **Изображения техники** — файл, подпись, порядок (первое по порядку — обложка).
   - **Значения характеристик** — техника + характеристика + значение (число / текст / да-нет / вариант).
5. **Дополнительные услуги** — фиксированные суммы за заявку (доставка, машинист и т. п.). **Настройки расчёта** — шаг округления, пометка о НДС, текст оговорки.

Массовое наполнение — **Импорт CSV** (ссылка в меню панели открывает кабинет → «Импорт CSV»): скачайте шаблон, заполните, сначала выполните «Только проверка», изучите отчёт, затем импортируйте. Повторный импорт того же файла обновляет карточки по `external_id` и не создаёт дублей. Подробно — `CSV_TEMPLATE.md`.

## Контент сайта

- **Настройки сайта** — контакты, режим работы, код карты, блок главной (заголовок, подзаголовок, изображение), «Коротко о компании», цифры (JSON-список `{"value","label"}`), текст подвала, SEO по умолчанию.
- **Страницы** — произвольные страницы `/<slug>` (о компании `about`, политика ПДн `privacy`, соглашение `terms`); «Ссылка в подвале».
- **Услуги**, **Проекты** (+ **Фото проектов**), **Публикации** — списки и детальные страницы; «Опубликована» скрывает/показывает.
- **Редиректы** — старый путь → новый (301 или 302), применяются сразу.
- SEO: у каждой сущности поля «SEO: заголовок», «SEO: описание», «изображение для соцсетей», «Не индексировать». `sitemap.xml` и `robots.txt` формируются автоматически.

Изменения видны на сайте в течение минуты (кэш публичных страниц 60 с).

## Заявки

Основная работа — в кабинете менеджера (`/manager/inquiries`): фильтры по статусу, ответственному, организации, датам, поиск; выгрузка CSV с текущими фильтрами; в карточке заявки — назначение ответственного, смена статуса (только допустимые переходы: Новая → Уточнение / Предложение направлено → Согласована → Завершена; Отменена из любого активного), комментарии (внутренние не видны клиенту), загрузка PDF-предложения, файлы клиента. Клиент получает письмо при смене статуса.

В панели раздел **Заявки** дублирует данные для просмотра и правки реквизитов; **История статусов**, **Комментарии**, **Файлы заявок**, **Сообщения с сайта** — вспомогательные.

## Обмен и журнал

- **Webhook: приёмники** — адреса внешних систем и секрет подписи (формат — `WEBHOOK.md`). **Исходящие (email, webhook)** — очередь со статусами и ошибками; для повторной отправки переведите запись в «В очереди». **Webhook: тестовый приёмник** — принятые доставки на тестовой среде.
- **Импорт CSV: журнал** — все запуски с отчётами.
- **Журнал действий** — кто, когда и что изменил (статусы и назначение заявок, роли, блокировки, каталог, тарифы, импорт, удаления).

## Удаление данных

Удаление в панели требует подтверждения. Технику, участвующую в заявках, удалить нельзя (снимите с публикации). Удаление организации или пользователя не удаляет их заявки (связь очищается).
