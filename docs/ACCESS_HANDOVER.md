# Передаваемые доступы (перечень; значения — отдельным защищённым каналом)

| Доступ | Где | Примечание |
|---|---|---|
| Репозиторий исходников | github.com/rosavskiy/dortech (или архив `dortech-v1.0.0.zip`) | тег `v1.0.0` |
| Сервер prod | SSH, пользователь, каталог `/srv/dortech/prod` | секреты в `/srv/dortech/prod/.env` |
| Сервер test | SSH, каталог `/srv/dortech/test`; basic-auth тестового домена | |
| Домен и DNS | регистратор / панель DNS Заказчика | |
| Панель управления | `https://<домен>/<ADMIN_URL_PATH>/`, администратор | смените пароль после передачи |
| Кабинет менеджера | `https://<домен>/manager/` | учётные записи менеджеров |
| SMTP | данные Заказчика, указаны в `.env` | |
| Секрет webhook | `WEBHOOK_SECRET` в `.env` и в панели «Webhook: приёмники» | |
| Резервные копии | `/srv/dortech/prod/backups`, cron `/etc/cron.d/dortech-backup` | рекомендуется внешнее хранилище |
