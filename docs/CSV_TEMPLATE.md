# Шаблон CSV для импорта каталога

Файл: UTF-8 (допускается BOM), разделитель `;` (допускается `,`), первая строка — заголовки. Шаблон с актуальным списком характеристик скачивается в кабинете администратора: «Импорт CSV → Скачать шаблон».

| Колонка | Обяз. | Описание |
|---|---|---|
| `external_id` | да | Внешний идентификатор (артикул, код 1С). Ключ дедупликации: повторный импорт обновляет карточку, а не создаёт новую |
| `name` | да | Название |
| `slug` | | Адрес карточки латиницей; если пусто — формируется из названия |
| `category` | да | Slug категории (из панели: Категории → Адрес) |
| `manufacturer` | | Название производителя; отсутствующий создаётся автоматически |
| `model` | | Модель |
| `year` | | Год выпуска, целое |
| `status` | | Код статуса доступности (`available`, `busy`, `on_request` или свои из панели) |
| `short_description` | | Краткое описание |
| `description`, `terms` | | Описание и условия аренды (допускается HTML) |
| `price_per_shift`, `price_per_day` | | Цены, ₽; пусто — тариф не задан (карточка «по запросу») |
| `shift_hours` | | Часов в смене (по умолчанию 8) |
| `min_units` | | Минимум смен/суток (по умолчанию 1) |
| `price_hidden` | | `1`/`0` — скрыть цену и показывать «запросить предложение» |
| `is_published`, `is_featured` | | `1`/`0` — опубликована / на главной |
| `sort` | | Порядок вывода |
| `images` | | Имена файлов через `\|`; файлы предварительно загружаются в `media/public/import/` |
| `meta_title`, `meta_description` | | SEO-поля |
| `attr:<код>` | | Значение характеристики по коду из словаря (число, текст, `1`/`0` или вариант списка; новый вариант добавляется в словарь с предупреждением) |

Правила: пустая ячейка не изменяет существующее значение (кроме цен — пустая цена снимает тариф); дубль `external_id` внутри файла — побеждает последняя строка; строка с ошибкой (нет категории, некорректное число) пропускается целиком и попадает в отчёт; при ошибке заголовков импорт не выполняется.

Режим «Только проверка» выполняет все проверки и формирует отчёт без записи в базу. Отчёт по строкам доступен в кабинете и выгружается в CSV.

Пример:

```
external_id;name;category;manufacturer;model;year;status;price_per_shift;price_per_day;attr:weight;attr:drive
EX-001;Экскаватор Komatsu PC200;ekskavatory;Komatsu;PC200;2021;available;12000;28000;20,5;Гусеничная
EX-002;Каток BOMAG BW213;katki;BOMAG;BW213;2019;busy;9000;;12,8;
```
